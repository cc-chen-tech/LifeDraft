## Why

The creative narrative modules have stable local contracts but are absent from the maintained backend suite, leaving story-quality regressions to be found late. Their verified tests cover emotional pacing, foreshadowing, novelty, and preference adaptation without AI-provider calls.

## What Changes

- Add the four existing creative narrative suites to both maintained backend workflows.
- Preserve ordered workflow parity and provider-free execution.

## Capabilities

### New Capabilities
- `creative-narrative-maintained-gate`: Require deterministic creative narrative contracts in the maintained backend suite.

### Modified Capabilities

- None.

## Impact

Only maintained workflow test lists change; no production or existing-test source changes are made.
