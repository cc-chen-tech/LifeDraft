## Why

The maintained backend gate does not yet exercise several deterministic narrative-consistency validators, so regressions in temporal, causal, and information-boundary rules can reach slower browser-oriented checks. These rules accept plain text and state and can be made part of the fast, reproducible backend signal.

## What Changes

- Promote the existing no-double temporal validator contract suite into both maintained backend workflows.
- Add direct no-double contracts for causal consequence and information-barrier validation using real dictionary and lightweight object contexts.
- Measure the expanded maintained gate twice and ratchet its coverage floor only when the result supports the next whole-percent threshold.

## Capabilities

### New Capabilities
- `harness-consistency-contract-coverage`: Deterministic backend contracts for temporal, causal, and information-boundary narrative validation.

### Modified Capabilities
- `test-gates`: The maintained backend gate includes stable harness consistency contracts and enforces the evidenced coverage floor.

## Impact

- Affects `tests/`, the two maintained backend workflow test lists, and their coverage threshold.
- Does not change runtime application behavior, provider configuration, database schemas, or existing test bodies.
