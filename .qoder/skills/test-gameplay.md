# 核心游戏循环功能回归测试

## 前置条件
- 前端运行在 http://localhost:3000
- 后端运行在 http://localhost:8000
- 使用测试账号：GameplayTestUser（需先创建游戏）
- 确保账号已有一个进行中的游戏存档

## 测试步骤

### TC-01: 游戏界面基本渲染
**操作**：
1. 使用账号 `GameplayTestUser` 登录（如未注册则先注册并创建一个游戏）
2. 进入游戏界面
3. 检查页面各区域元素

**预期结果**：
- 故事文本区域可见且有内容
- 选项按钮正常显示（至少1个可点击选项）
- 资源面板可见（能量/心情/知识/财富等数值）

**截图**：截图并记录路径

### TC-02: 选择游戏选项
**操作**：
1. 在游戏界面找到可用选项
2. 点击其中一个选项
3. 等待加载状态出现并完成
4. 等待新故事文本生成

**预期结果**：
- 点击后出现加载指示器
- 加载完成后新故事文本显示
- 新的选项出现供继续选择
- 故事内容与所选选项相关

**截图**：加载中和加载完成各截一张图

### TC-03: 资源变化追踪
**操作**：
1. 记录当前资源数值（能量/心情/知识/财富）
2. 选择一个选项并等待故事生成
3. 记录选择后的资源数值
4. 对比前后变化

**预期结果**：
- 资源数值在选择后有合理变化
- 数值变化与故事情节逻辑一致
- 资源面板实时更新，无延迟

**截图**：选择前后各截一张图

### TC-04: 自定义选择
**操作**：
1. 在游戏界面查找自定义输入框（如有）
2. 在输入框中输入自定义行动文本
3. 提交自定义选择
4. 等待AI响应

**预期结果**：
- 自定义输入框可正常输入
- 提交后AI生成与自定义行动相关的故事
- 响应内容合理，与输入行动相关
- 如无自定义输入框，标记为N/A

**截图**：截图并记录路径

### TC-05: 轮次小结显示
**操作**：
1. 持续进行游戏选择直到完成一轮
2. 等待轮次小结出现
3. 查看小结内容

**预期结果**：
- 轮次小结文本正常出现
- 小结内容概括了本轮的关键事件
- 小结格式清晰可读

**截图**：截图并记录路径

### TC-06: 周进度推进
**操作**：
1. 完成当前轮次后，查找"进入下一周"按钮
2. 点击"进入下一周"按钮
3. 等待新事件生成

**预期结果**：
- "进入下一周"按钮可见且可点击
- 点击后成功推进到新的一周
- 新事件/故事内容生成并显示
- 周数计数器正确更新

**截图**：截图并记录路径

### TC-07: 流式文本显示
**操作**：
1. 触发一次新的故事生成（选择选项或进入下一周）
2. 仔细观察文本显示过程
3. 确认文本逐步流出效果

**预期结果**：
- 文本以流式方式逐步显示
- 显示过程流畅无卡顿
- 文本完整无截断
- 最终显示内容完整且格式正确

**截图**：截图并记录路径

### TC-08: 控制台无错误
**操作**：
1. 打开浏览器开发者工具 Console 面板
2. 清除已有日志
3. 进行一次完整的游戏操作（选择选项→等待响应→查看结果）
4. 检查Console输出

**预期结果**：
- 无 401 Unauthorized 错误
- 无 404 Not Found 错误
- 无 500 Internal Server Error 错误
- 无 JavaScript 运行时异常

**截图**：截图Console面板并记录路径

## 通过标准
- 所有TC全部通过
- 无控制台错误
- 截图完整

## 输出格式
返回每个TC的通过/失败状态和截图路径列表
