# 故事总结功能回归测试

## 前置条件
- 前端运行在 http://localhost:3000
- 后端运行在 http://localhost:8000
- 使用测试账号：SummaryTestUser（需在游戏中进行多轮后测试）

## 测试步骤

### TC-01: 轮次小结显示
**操作**：完成一轮选择后，观察游戏界面
**预期结果**：轮次小结文本出现在游戏界面中
**截图**：截图并记录路径

### TC-02: 小结内容准确性
**操作**：阅读轮次小结内容
**预期结果**：小结涉及本轮关键事件和玩家所做的选择
**截图**：截图并记录路径

### TC-03: 周进度面板
**操作**：查看周进度面板
**预期结果**：当前周数、已完成轮次信息显示正确
**截图**：截图并记录路径

### TC-04: 总结API可用性
**操作**：浏览器访问后端 POST /api/games/{gameId}/summary
**预期结果**：API 返回非 404 响应，确认端点存在
**截图**：截图并记录路径

### TC-05: 多轮累计总结
**操作**：进行 3 轮以上游戏
**预期结果**：历史事件在游戏中可回顾
**截图**：截图并记录路径

### TC-06: 新的一周开始时总结
**操作**：点击"进入下周"
**预期结果**：上周总结/回顾内容显示
**截图**：截图并记录路径

### TC-07: 总结与资源关联
**操作**：查看总结中提到的资源变化
**预期结果**：总结中描述的资源变化与实际资源面板数值一致
**截图**：截图并记录路径

### TC-08: 空游戏状态
**操作**：新游戏刚开始时查看总结区域
**预期结果**：无总结内容显示，且页面无报错
**截图**：截图并记录路径

## 通过标准
- TC-01 ~ TC-08 全部通过
- 所有页面无控制台错误
- 总结内容与游戏实际进度一致
- API 端点正常响应
