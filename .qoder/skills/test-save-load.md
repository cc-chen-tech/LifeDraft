# 存档管理功能回归测试

## 前置条件
- 前端运行在 http://localhost:3000
- 后端运行在 http://localhost:8000
- 使用测试账号：SaveTestUser（需先有一个进行中的游戏）

## 测试步骤

### TC-01: 查看存档列表
**操作**：导航到 /saves 页面
**预期结果**：存档列表正常显示，包含已有存档卡片
**截图**：截图并记录路径

### TC-02: 自动保存验证
**操作**：创建一个新游戏并完成初始化流程
**预期结果**：游戏创建后自动生成存档，/saves 页面可见新存档
**截图**：截图并记录路径

### TC-03: 加载存档
**操作**：在存档列表中点击一个已有存档
**预期结果**：游戏界面恢复，显示存档对应的故事内容和角色状态
**截图**：截图并记录路径

### TC-04: 多存档管理
**操作**：创建第二个游戏，然后返回 /saves 页面
**预期结果**：存档列表中显示两个存档，各存档信息独立正确
**截图**：截图并记录路径

### TC-05: 删除存档
**操作**：在存档列表中删除一个存档（点击删除按钮并确认）
**预期结果**：存档从列表中移除，列表自动更新
**截图**：截图并记录路径

### TC-06: 存档信息完整性
**操作**：查看存档卡片的显示内容
**预期结果**：存档卡片正确显示角色名、保存时间、游戏周数等信息
**截图**：截图并记录路径

### TC-07: 加载后游戏状态一致
**操作**：加载一个存档，检查游戏内各项状态
**预期结果**：故事内容、角色资源状态与保存时完全一致
**截图**：截图并记录路径

### TC-08: 空存档状态
**操作**：使用新账号（无任何存档）访问 /saves 页面
**预期结果**：显示"暂无存档"或类似的空状态提示
**截图**：截图并记录路径

## 通过标准
- 全部 8 个测试用例通过
- 存档的增删查改流程完整无报错
- 存档数据与游戏状态保持一致
- 空状态和多存档场景均正常处理
