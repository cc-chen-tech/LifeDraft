# 认证系统功能回归测试

## 前置条件
- 前端运行在 http://localhost:3000
- 后端运行在 http://localhost:8000
- 使用测试账号：AuthTestUser

## 测试步骤

### TC-01: 新用户注册
**操作**：
1. 打开 http://localhost:3000
2. 找到并点击登录/注册入口
3. 输入用户名 `AuthTestUser`
4. 提交注册请求
5. 等待系统返回私钥

**预期结果**：
- 系统生成并显示私钥
- 出现注册成功提示消息
- 页面显示已登录状态，展示用户名 `AuthTestUser`

**截图**：截图并记录路径

### TC-02: 使用私钥登录
**操作**：
1. 如当前已登录，先登出
2. 点击登录入口
3. 选择使用私钥登录
4. 输入 TC-01 中获取的私钥
5. 提交登录

**预期结果**：
- 登录成功，显示欢迎消息
- 页面展示用户名 `AuthTestUser`

**截图**：截图并记录路径

### TC-03: 页面刷新后保持登录
**操作**：
1. 确认当前已登录状态
2. 刷新页面（F5 或浏览器刷新）
3. 等待页面加载完成

**预期结果**：
- 刷新后仍显示已登录状态
- 用户名 `AuthTestUser` 仍然可见
- 无需重新登录

**截图**：截图并记录路径

### TC-04: 跨页面导航保持登录
**操作**：
1. 确认当前在首页且已登录
2. 导航到存档页面
3. 确认存档页面登录状态
4. 返回首页
5. 确认首页登录状态

**预期结果**：
- 每个页面都保持登录状态
- 用户名 `AuthTestUser` 在所有页面可见
- 导航过程中无登录中断

**截图**：每个页面各截一张图并记录路径

### TC-05: 登出功能
**操作**：
1. 确认当前已登录
2. 找到并点击登出按钮
3. 等待登出完成

**预期结果**：
- 成功登出，返回未登录状态
- 页面不再显示用户名
- 登录/注册入口重新出现

**截图**：截图并记录路径

### TC-06: 登出后重新登录
**操作**：
1. 确认当前为未登录状态（TC-05 之后）
2. 点击登录入口
3. 使用 TC-01 中获取的私钥登录
4. 提交登录

**预期结果**：
- 登录成功，恢复已登录状态
- 显示用户名 `AuthTestUser`
- 之前的用户数据（如有）仍然存在

**截图**：截图并记录路径

### TC-07: 无效私钥登录失败
**操作**：
1. 如当前已登录，先登出
2. 点击登录入口
3. 输入一个错误的私钥（如 `invalid-key-12345`）
4. 提交登录

**预期结果**：
- 登录失败，显示错误提示信息
- 保持未登录状态
- 页面不崩溃，可以继续操作

**截图**：截图并记录路径

## 通过标准
- 所有TC全部通过
- 无控制台错误
- 截图完整

## 输出格式
返回每个TC的通过/失败状态和截图路径列表
