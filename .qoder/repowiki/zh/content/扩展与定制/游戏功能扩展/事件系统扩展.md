### 事件生成流程

事件生成采用异步流式处理，支持断线重连和并发控制：

```mermaid
sequenceDiagram
participant Client as 客户端
participant API as API路由
participant Lock as 并发锁
participant Generator as 事件生成器
participant AI as AI生成器
participant Player as 玩家状态
Client->>API : GET /{game_id}/event
API->>Lock : 获取游戏锁
Lock-->>API : 锁定成功
API->>Generator : generate_round_event()
Generator->>Player : 检查现有事件
alt 有现有事件
Player-->>Generator : 返回现有事件
else 无现有事件
Generator->>AI : 生成事件
AI-->>Generator : 返回事件数据
Generator->>Player : 更新状态
end
Generator-->>API : 返回事件
API-->>Client : SSE流式响应
```

## 详细组件分析

### 事件分类系统扩展

事件系统支持三种主要分类：日常事件、重大事件和随机事件。

#### 日常事件（Round Events）

日常事件是每回合自动触发的基础事件：

```mermaid
flowchart TD
Start([开始回合]) --> CheckExisting{检查现有事件}
CheckExisting --> |有事件| ReturnExisting[返回现有事件]
CheckExisting --> |无事件| BuildContext[构建事件上下文]
BuildContext --> GenerateAI[AI生成事件]
GenerateAI --> ValidateEvent[验证事件质量]
ValidateEvent --> HasOptions{有选项?}
HasOptions --> |否| FallbackEvent[生成回退事件]
HasOptions --> |是| ApplyEffects[应用事件效果]
FallbackEvent --> ApplyEffects
ApplyEffects --> UpdateState[更新玩家状态]
UpdateState --> End([结束回合])
ReturnExisting --> End
```

## 故障排除指南

### 常见问题及解决方案

#### 事件生成超时
**症状**：事件生成长时间无响应
**解决方案**：
1. 检查AI服务可用性
2. 验证网络连接
3. 查看日志中的超时信息

#### 并发冲突
**症状**：多个请求同时访问导致状态不一致
**解决方案**：
1. 检查异步锁状态
2. 验证生成标志位
3. 实施重试机制

#### 数据验证错误
**症状**：事件数据格式不正确
**解决方案**：
1. 检查Pydantic模型定义
2. 验证数据类型和范围
3. 实施数据修复逻辑
