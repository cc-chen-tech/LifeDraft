## Provider boundary

Running the entire affected file after repairing game setup also exposed a previously vacuous progression test. Its broad button matcher clicked the transcript toggle, then looked for an obsolete header. It now clicks an actual numbered choice, requires a successful choice response, checks exactly one matching persisted settlement receipt and the visible next-day date. It does not claim subsequent chapter generation. Successful completion cancels the SSE reader, so Chromium response-body retrieval is not used as a completion oracle. The pre-fix failure was observed in the expanded run.

`E2E_DETERMINISTIC_STORY=1` remains the only activation path. The client passes the actual budget and prompt to the existing isolated provider. Chinese fixtures cover modern and South Song settings at fast/expert/master budgets; complete sentences are appended until the localized minimum is met. Production shape, era, required-cast and continuity validators remain active and unchanged.

The optional consistency model judge receives a deterministic response in this mode only when its full extracted candidate exactly matches a known deterministic fixture. Previously it fell through to the CI dummy API key after fixing prose length. This replaces a model response at the E2E provider boundary; it does not disable the production validator. A disabled-mode regression verifies that normal calls still fall through to the real provider. English fixture expansion is outside these Chinese failures and has not been claimed as repaired.
